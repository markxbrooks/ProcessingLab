XDSAUTO Short Documentation

February 2005 version. pierre.legrand@synchrotron-soleil.fr Please send e-mails for more help!

Dependencies

  • Python version > 2.1 (I guess)

  • XDS package.

Comnand Line Options

xdsauto.py [-O2] [-T1] [-1]

-O[1-4]

Number of profile fitting optimization steps. Default = 2.

-T[1-x]

Number of parallel threads (for ESRF openmosix clusters). Defaul automaticaly determined.

-x

Go directly to step x, from 1 to 5.



XDSAUTO Steps

  1. Peak Search

  2. Auto-indexing

  3. Integrate and Optimize Profiles

  4. Testing Laue Symmetries

  5. Integration and Scaling

Input file format: auto.par

Example of input file (auto.par)


frame_first = 1

frame_last = 120

phi_init = -90.000

delta_phi = 0.700

prefix = e01_img_

suffix = mccd

beam_x = 79.101

beam_y = 81.239

wavelength = 0.9792

distance = 210.000


anomalous = yes (optional, default: no)

beamline = ESRF_ID13 (optional, default: ESRF_BM30A)

spg = i213 (optional, default: unknown = 0)

cell = a b c alpha beta gamma (optional, default = 0)

img_dir = ../img (optional, default: img_dir = ../img)

resolution_range = 50 2. (optional, default: 30 0 = max resolution)


angle_det = 0.000 not working yet

Other jiffy programs

xscale.py, xdsconv.py... use -h on the command line to have the options.

runxds.py can be used to rerun xds and saving the logfiles incrementaly. If used with the -a option, it will run only the DEFPIX, INTEGRATE and CORRECT steps with updated profiles parameters from the last run and updated XPARM.XDS from GXPARM.XDS.
